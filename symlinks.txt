# シンボリックリンク定義 (mise run link / unlink が参照)
# 書式: <リンク先 ($HOME からの相対パス)>:<元ファイル (リポジトリルートからの相対パス)>
# 元ファイル末尾が `*` の行は配下の各エントリを個別にリンクする (リンク先側の `*` が各エントリ名に置き換わる)
.zshrc:zsh/.zshrc
.zshrc.local:zsh/.zshrc.local
.zshenv:zsh/.zshenv
.zprofile:zsh/.zprofile
.config/nvim:nvim
.config/starship.toml:starship.toml
.config/wezterm:wezterm
.config/tmux/tmux.conf:tmux/tmux.conf
.config/mise:mise
.config/atuin:atuin
.config/sheldon:sheldon
.config/act:act
# AI エージェント設定 (agents/)。共通ルール・スキル・チェックリストは両ツールで共有し、ツール固有のものは agents/claude, agents/codex に置く
# スキルはスキル単位でリンクし、各ツールが生成するローカル専用スキルと同居できるようにする
.codex/AGENTS.md:agents/private/AGENTS.md
.claude/CLAUDE.md:agents/private/AGENTS.md
.claude/checklists:agents/checklists
.claude/settings.json:agents/claude/settings.json
.claude/agents:agents/claude/agents
.claude/hooks:agents/claude/hooks
.claude/statusline-command.sh:agents/claude/statusline-command.sh
.codex/dotfiles.config.toml:agents/codex/dotfiles.config.toml
.claude/skills/*:agents/skills/*
.claude/skills/*:agents/private/skills/*
.agents/skills/*:agents/skills/*
.agents/skills/*:agents/private/skills/*
.config/flipper:flipper
.config/github-copilot:github-copilot
.cowsay:cowsay
# Claude Code のユーザー設定 (MCP サーバー・OAuth 等)。機密を含むため .gitignore 対象。各マシンで ~/.claude.json を claude.json に移してから link する
.claude.json:claude.json
.gitconfig:git/.gitconfig
.gitconfig.local:git/.gitconfig.local
.ssh/config:ssh/config
