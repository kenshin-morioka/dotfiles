# セルフレビュースキル

コミット前に変更内容をチェックリストに照合し、問題がないか検証する。

## Step 1: 変更内容の把握

作業ツリーの変更（ステージ済み・未ステージの両方）をまとめて取得する:

```bash
git diff HEAD
```

作業ツリーに変更がない場合のみ、直近コミット（`git diff HEAD~1`）を対象にする。

## Step 2: チェックリストの検出と選択

`~/.claude/checklists/` 配下の全 `.md` ファイルを検出する。

- `default.md` は常に適用する
- それ以外はファイル名と変更ファイルの種類で適用を判定する:
  - 変更に `.rb` ファイル（`_spec.rb` 以外）が含まれる → `rails.md`
  - 変更に `_spec.rb` ファイルが含まれる → `rspec.md`
  - 上記以外のチェックリストが存在する場合は、ファイル名から推測して適用判定する（例: `terraform.md` → `.tf` ファイル）
- 判定できないチェックリストがある場合はスキップする

検出したチェックリストを全て読み込む。

## Step 3: 照合と検証

変更内容に対して、該当する全チェックリスト項目を**一括で**照合する。

- 各項目について、変更内容が違反していないかを検証する
- 該当しない項目はスキップする

## Step 4: レポート出力

```markdown
# Self-Review Report

## 対象
- 変更ファイル: N files
- 適用チェックリスト: {適用したファイル名一覧}

## 検証結果

### 違反あり
- [ ] {チェック項目} — {具体的な違反箇所と理由}

### 注意（確認推奨）
- [~] {チェック項目} — {確認が必要な理由}

### 問題なし
- [x] 検証した項目数: N

## 総合判定
{PASS / NEEDS_FIX}
```

NEEDS_FIX の場合は違反箇所の修正案も提示する。
